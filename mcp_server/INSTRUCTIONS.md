Galaxy Cluster Catalogs MCP Server: Planck PSZ2, SPT-SZ 2500d (Bocquet+19), SPTpol 100d, SPT-ECS, SPT-3G Main 5yr, ACT DR6 and eROSITA eRASS1 (primary + cosmology) cluster catalogues. Start with list_clusters_datasets; list_clusters_skills for recipes (clusters-tour first). fetch_cluster_catalog downloads a catalogue on first use and writes a harmonised CSV (name, ra, dec [deg J2000], z, z_err, M500 [1e14 Msun, M500c], M500_err_lo/hi, snr, survey, dataset; NaN = missing); every other catalogue tool takes those CSV paths (or a dataset key for the full catalogue). Units/conventions: M500 is each survey's own estimate - SPT (xi-mass, WL+X-ray calibrated, h70), ACT DR6 (WL-consistent normalisation, Eddington-corrected), Planck PSZ2 MSZ (hydrostatic Y-M, expect ~20% lower, 1-b~0.8), eRASS1 (count-rate-mass, native 1e13 Msun converted). snr is survey-native (xi / SNR / EXT_LIKE) and NOT comparable across surveys. predict_cluster_counts_lcdm (heavy) uses Tinker+08 x Eisenstein-Hu P(k) with no selection function: use mass thresholds where samples are ~complete. Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. Heavy tools can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
